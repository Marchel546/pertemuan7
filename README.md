# MyTaskList App

Aplikasi To-Do List sederhana yang dibangun menggunakan React Native (Expo) untuk memenuhi Tugas Praktikum Minggu 7.

**Nama:** Livelihood Marchel Samuel Simangunsong  
**NIM:** 243303621257

## 📋 Deskripsi
MyTaskList adalah aplikasi task manager dinamis yang memungkinkan pengguna untuk mencatat tugas harian mereka. Aplikasi ini dilengkapi dengan manajemen prioritas, filter status tugas, serta UI yang dioptimalkan untuk pengalaman pengguna.

## ✨ Fitur yang Diimplementasikan
- [x] **Setup & Running:** Berhasil dijalankan di HP fisik via Expo Go.
- [x] **Komponen & UI:** Menggunakan `View`, `Text`, `TouchableOpacity`, `StyleSheet`, dan Flexbox.
- [x] **State Management:** Menggunakan `useState` untuk input dan array data.
- [x] **Form & Validasi:** Menggunakan `TextInput`, `KeyboardAvoidingView`, dan alert jika input kosong.
- [x] **List Dinamis:** Menggunakan `FlatList` dengan `ListEmptyComponent`.
- [x] **CRUD Dasar:** Fitur Add dan Delete task.
- [x] **[BONUS] Mark as Done:** Fitur centang task selesai.
- [x] **[BONUS] Prioritas Task:** Label Tinggi/Sedang/Rendah dengan warna custom.
- [x] **[BONUS] Counter Task:** Indikator "X dari Y task selesai".
- [x] **[BONUS] Filter View:** Tab Semua / Aktif / Selesai.
- [x] **[BONUS] Profesional UI:** Tema gelap yang rapi dan responsif.

## 🚀 Cara Menjalankan Project
1. Clone repository ini.
2. Install dependencies dengan perintah `npm install`.
3. Jalankan server expo dengan `npx expo start`.
4. Scan QR code menggunakan aplikasi Expo Go di smartphone Anda.
